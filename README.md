# Календарь ВГИКа

Готовый `public/calendar.ics` отдаётся как обычный статический файл и не может
упасть по тайм-ауту Netlify Functions. GitHub Actions проверяет расписание каждые
два часа. Если ВГИК временно недоступен, старая исправная версия сохраняется.

## Первое включение

1. Замените содержимое существующего GitHub-репозитория файлами из этого проекта.
2. Откройте в GitHub вкладку **Actions** и разрешите workflows, если появится кнопка.
3. Выберите **Обновить календарь ВГИКа** → **Run workflow**.
4. После зелёной галочки Netlify сам опубликует новый файл.

Ссылка остаётся прежней: `/calendar.ics`.
