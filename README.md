# Календарь расписания ВГИКа

Минимальный Netlify-проект, который формирует только обновляемую подписку
iCalendar для группы «1 Мастерская Алибекова А. С. (2026)».

После публикации проекта постоянная ссылка календаря будет такой:

```text
https://ВАШ-САЙТ.netlify.app/calendar.ics
```

1. Откройте «Календарь» → «Календари» → «Добавить».
2. Выберите «Добавить подписной календарь».
3. Вставьте ссылку `https://ВАШ-САЙТ.netlify.app/calendar.ics`.
4. Сохраните календарь в iCloud.

Календарь охватывает две прошедшие, текущую и восемь следующих учебных недель.
При каждом обновлении подписки данные заново берутся с сайта ВГИКа. iPhone сам
выбирает момент синхронизации, поэтому изменения могут появиться не мгновенно.

Для работы автообновления опубликуйте весь каталог проекта через подключённый к
Netlify GitHub-репозиторий. Обычная ручная загрузка ZIP не публикует функцию.
